# Online Courses Catalog

Adaptive course catalog based on the Figma test task.

## Stack

- HTML
- Vanilla JavaScript
- SCSS
- BEM naming

## What is implemented

- Responsive layout from 1920px down to 320px.
- Live search by course title.
- Category filtering with course counters.
- Load more button.
- Stable decorative background that does not jump when the number of cards changes.
- Placeholder teacher images for extra mock cards.
- Vercel-ready static project config.

## Commands

```bash
npm install
npm run start
```

For SCSS development:

```bash
npm run sass:watch
```

For production build before Vercel:

```bash
npm run build
```
